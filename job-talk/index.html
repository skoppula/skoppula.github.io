Where the targets are

One headline score, two diagnostics that split it

headline

Existence-aware AJ (EA-AJ)

  1. Keep predictions the model says exist.
  2. Hungarian-match them to true surfaces by median position error.
  3. Score matched pairs at every frame, hidden ones included.

EA-AJ = ⅕ Σd TPd / (|G| + |P| − TPd)

A missed surface adds to |G|; an invented one adds to |P|. Score 1 only if you find every surface and nothing else.

diagnostic · whether

Detection AP

Rank all predictions by existence score, as in object detection. A hit is a median error ≤ 4 px at 256² (or 10% of depth in 3D). Needs no cutoff.

Answers: does it find the surfaces and rank them above inventions?

diagnostic · where

Localization δavg

Hungarian-match over all predictions, ignoring existence, then TAP-Vid's fraction within thresholds.

Answers: when it tracks a surface, how close is it?

Both diagnostics are also reported beyond the first visible surface, where any single-surface tracker scores exactly 0, and by slice: glass, behind glass, fronts, backs, moving, static, hidden-then-seen, never seen.

Four things an audit of our own numbers caught, and the fix for each

1 · a metric rewarded doing nothing

Copying the first track into all 8 slots scores .588 localization beyond the first surface with .006 detection AP. Hidden surfaces often project near the visible one.

Fix: never report localization without detection; keep the untrained copy as a reference row.

2 · a slice that never moved

The behind-glass slice was flat for every model, single-surface controls included. Cause: glass missing from instance masks, so slot 0 leaked into the slice.

Fix: sanity-check every slice against a model that should score 0 on it.

3 · rankings inside the noise

Five CoTracker3 variants spanned 2D EA-AJ .309 to .316, and their order changed between test sets.

Fix: paired bootstrap intervals over scenes; no design credit without a seed spread.

4 · a fix that only helped one family

An existence verifier raised CoTracker3's detection AP beyond the first surface (.342 → .398) but cut ARROW's EA-AJ (.313 → .295).

Fix: report both. A component's effect is a property of the pair, not the component.

Degenerate baselines are tests for the metric. If "copy", "static" or "front of the same object" scores well, the metric is measuring something else.

Fun questions along the way

How do we design scoring rubrics and verifiers for hidden trajectories that have no visual grounding? Plausible outputs should not be penalized even if they are not GT!

Baselines cost ~10,000 GPU-hours here. What is the smallest eval that preserves the ranking, and how do you verify that it does?

When LLMs write the environments, when does the generator's taste become the thing models overfit to?
